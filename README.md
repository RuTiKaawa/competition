#代码库
请大家把代码提交到这里哦，每个人先创建自己的文件夹方便归档整理
常见git提交指令如下：
#
  git clone <仓库地址>
  
  cd <仓库目录>

  将文件复制到这里或直接修改
  
  git status
  
  git add .
  
  git commit -m "提交说明"
  
  git push origin main

  如果默认分支不是 main，先查看：

  git branch --show-current

  首次推送当前分支可用：

  git push -u origin 当前分支名

  注意：复制原项目文件时，不要把原来的 .git 目录一起复制进来。
