# 制造企业智能问析系统 —— 接口协议文档 (V1.2)

本文档定义了前端、Agent 服务与业务后端之间的交互协议。所有接口请求与响应均采用 JSON 格式，字符集统一为 UTF-8。

---

## 1. Agent 交互接口（前端 ↔ Agent）

### 1.1 Agent 对话接口
*   **请求路径**: `POST /api/agent/chat`
*   **接口说明**: 前端向 Agent 发送用户的自然语言提问，Agent 规划并执行后，返回结构化的图表、数据或文本洞察。
*   **请求体示例**:
    ```json
    {
      "session_id": "abc123",
      "question": "各工序良率对比"
    }
    ```
*   **响应体示例**:
    ```json
    {
      "type": "chart",              // 渲染类型: "table" | "chart" | "report"
      "table": {                    // 当 type=table 或 chart 时返回
        "columns": ["工序", "良率"],
        "rows": [
          ["冲压", 0.982],
          ["焊接", 0.951]
        ]
      },
      "chart": {                    // 当 type=chart 或 report 时返回
        "title": "各工序良率对比",
        "chart_type": "bar",        // 仅限: "bar" | "line" | "pie" | "scatter"
        "x_data": ["冲压", "焊接", "装配"],
        "y_data": [98.2, 95.1, 97.8],
        "option": {}                // 完整的 ECharts option（可选）
      },
      "insight": "冲压工序良率最高，为98.2%；焊接工序良率最低，为95.1%，建议重点排查焊接质量问题。",
      "sql_display": "SELECT process_name, ...",   // 展现给用户看的 SQL
      "tables_used": ["process_yield", "quality_inspection"]  // 涉及的物理表名
    }
    ```

## 2. 元数据及业务接口（Agent ↔ 后端）

### 2.1 获取全部表元数据
*   **请求路径**: `GET /api/metadata/tables`
*   **接口说明**: Agent 用于获取数据库内所有表及字段的结构与释义，以便进行精准的 SQL 翻译。
*   **响应体示例**:
    ```json
    {
      "code": 200,
      "data": [
        {
          "table_name": "process_yield",
          "table_comment": "工序产量表，记录每道工序每天的产量和合格数量",
          "columns": [
            {
              "column_name": "process_name",
              "column_type": "VARCHAR",
              "column_comment": "工序名称，如'冲压'、'焊接'、'装配'",
              "sample_values": "冲压, 焊接, 装配"
            },
            {
              "column_name": "qty",
              "column_type": "INTEGER",
              "column_comment": "当日生产总数（单位：件）",
              "sample_values": "350, 420, 380"
            }
          ]
        }
      ],
      "message": "success"
    }
    ```

### 2.2 获取指定表元数据
*   **请求路径**: `GET /api/metadata/tables/{table_name}`
*   **接口说明**: 获取某张特定表的详细 Schema 信息。
*   **响应体示例**:
    ```json
    {
      "code": 200,
      "data": {
        "table_name": "process_yield",
        "table_comment": "工序产量表",
        "columns": [
          {
            "column_name": "process_name",
            "column_type": "VARCHAR",
            "column_comment": "工序名称，如'冲压'、'焊接'、'装配'",
            "sample_values": "冲压, 焊接, 装配"
          }
        ]
      },
      "message": "success"
    }
    ```

## 3. SQL 执行接口（Agent ↔ 后端）

### 3.1 SQL 安全查询接口
*   **请求路径**: `POST /api/data/query`
*   **接口说明**: Agent 在沙箱中校验代码安全后，向后端请求执行 SQL 并获取扁平化结果数据。
*   **约束条件**: 查询超时限制为 5 秒，单次查询最多返回 200 行记录。
*   **请求体示例**:
    ```json
    {
      "sql": "SELECT process_name, SUM(qty) as total_qty FROM process_yield WHERE prod_date >= '2026-06-01' GROUP BY process_name"
    }
    ```
*   **成功响应体示例**:
    ```json
    {
      "code": 200,
      "data": {
        "columns": ["process_name", "total_qty"],
        "rows": [
          ["冲压", 12500],
          ["焊接", 11800]
        ],
        "row_count": 2
      },
      "message": "success"
    }
    ```
*   **错误响应体示例**:
    ```json
    {
      "code": 400,
      "data": null,
      "message": "SQL语法错误: syntax error at or near \"FROM\""
    }
    ```

## 4. 图表构建接口（Agent ↔ 后端）

### 4.1 动态图表 Option 生成接口
*   **请求路径**: `POST /api/chart/build`
*   **接口说明**: Agent 将处理后的结构化数据发送给后端，由后端（或图表引擎）统一转换为符合前端展示要求的标准 ECharts Option 配置。
*   **请求体示例**:
    ```json
    {
      "chart_type": "bar",
      "title": "各工序良率对比",
      "x_data": ["冲压", "焊接", "装配"],
      "y_data": [98.2, 95.1, 97.8]
    }
    ```
*   **响应体示例**:
    ```json
    {
      "code": 200,
      "data": {
        "option": {
          "title": { "text": "各工序良率对比" },
          "xAxis": { "type": "category", "data": ["冲压", "焊接", "装配"] },
          "yAxis": { "type": "value" },
          "series": [{ "data": [98.2, 95.1, 97.8], "type": "bar" }]
        }
      },
      "message": "success"
    }
    ```

## 5. 业务知识接口（Agent ↔ 后端）

### 5.1 业务语义搜索
*   **请求路径**: `GET /api/knowledge/search?keyword=良率`
*   **接口说明**: Agent 用于模糊搜索业务指标公式、专有名词和关联物理表，是语义消歧（RAG）的关键支撑。
*   **响应体示例**:
    ```json
    {
      "code": 200,
      "data": {
        "objects": [
          { "name": "工序", "description": "生产过程中的加工环节，如冲压、焊接、装配" }
        ],
        "indicators": [
          {
            "name": "良率",
            "formula": "合格数量 / 生产总数",
            "tables": ["process_yield"],
            "fields": ["qual_qty", "qty"]
          }
        ],
        "themes": [
          {
            "name": "质量分析",
            "sample_questions": ["各工序良率对比", "不良品排行", "缺陷类型分布"]
          }
        ]
      },
      "message": "success"
    }
    ```
